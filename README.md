# The Weird-Esoteric Altar · 探灵

> 中国怪谈、妖怪与志异记录的档案库 —— **越往下越深**。

**在线访问**：https://linze-yu.github.io/weird-altar-iceberg/

---

## 这是什么

The Weird-Esoteric Altar（探灵）的**公开源库**。包含三部分：

```
wiki/     档案原文（Markdown）
site/     冰山图站点（GitHub Pages 发布）
tools/    提取器与构建工具
```

## 目录结构

```
wiki/entities/cbaigui/        3,582 个妖怪实体档案
  ├── 基本信息      表格化属性（种类/特性/外形/分布/民族/朝代/世界）
  ├── 基本介绍      原文叙述
  ├── 文献资料      古籍原文引用（公有领域）
  ├── 关联妖怪      横向关联
  └── 数据来源      cbaigui.com 原站链接

wiki/concepts/                 90 个概念页
  ├── ancient-text-*  37 个古籍页
  ├── type-*          33 个类型 hub
  ├── dynasty-*       14 个朝代页
  └── moc-by-*         5 个导航枢纽

wiki/entities/miao-jiang-gu-shi/   31 个《苗疆鬼事》人物档案
```

## 从原文重建站点

```bash
# 1. 提取词条
python3 tools/extract_entries.py wiki/entities/cbaigui entries.json

# 2. 字体子集化 + 数据分层
python3 tools/optimize_site.py .
```

## 数据来源

- **妖怪实体**：cbaigui.com（纪妖）公开数据集，逐条保留原始来源链接
- **古籍文献**：公有领域古籍原文（《山海经》《太平广记》《广异记》《搜神记》等）
- **《苗疆鬼事》**：本地创作叙事
