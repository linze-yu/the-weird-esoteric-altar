# 张伟国

## 基本档案

- **年龄**：40-50 岁
- **外貌**：地中海发型的矮胖男人
- **职业**：国家宗教事务局某负责人
- **身份**：本次湾浩广场行动的具体负责人
- **现状**：收网完成，准备与陆左深谈

## 关键行为

### 第二十九章：正式登场
- 矮胖男人 + 地中海发型
- 用胡萝卜粗的手指搭在陆左脖子侧边动脉
- 检测陆左是否被附身
- "没有被上身啊？难道是吓傻了？"
- **摸到陆左挂槐木牌的红线处**
- 陆左憋足劲："国家宗教管理局么？"
- **张伟国惊讶：知道得不少啊**

### 第二十九章：骂下属
- "黄鹏飞，夏宇新，曹彦君，骂了隔壁，你们这些扑街仔还不赶快干活？温吞吞地等着吃屎么？"
- 显示强势性格

### 第二十九章：处理现场
- 让黄鹏飞+夏宇新+曹彦君等处理被附身的小东+曼丽
- 让人把老王、许永生、地翻天铐上运出去
- 派人送陆左、杂毛小道、赵中华去军分区医院
- 指示：先治疗，后续事情过几天再说

### 第二十九章：表达对欧阳指间的敬意
- 看到燃烧的火焰
- 想灭火 → 赵中华说不行
- 所有人敬礼三秒
- 张伟国："这种玉石俱焚的法术，实在是……"

### 第三十章：与陆左对话
- 看到陆左提到陈志程，**立刻多了几分尊重**
- "不看僧面看佛门"
- "有些事情，我们是需要好好谈一谈了"

- "先去医院安心治疗"
- "后续的事情，等过几天再说"

### 重视人脉
- 听到陈志程名字立刻变脸
- 对陆左 + 杂毛小道的态度变尊重

## 实体档案价值

张伟国是**第十二卷最重要新人物**：
1. **国家宗教事务局的代表**（首次正式登场）
2. **与陈志程同系统**（大师兄关系网）
3. **强势 + 务实**（领导风范）
4. **重视人脉**（听到陈志程变脸）
5. **后续与陆左深谈**（重要伏笔）

他代表**陆左进入国家级别的视野**，意味着：
- 后续行动将与国宗局合作
- 共济会 / 邪灵教的更大布局将展开
- 大师兄陈志程将正式登场
