# 小美·江盈美

> **饰品店店长** · 陆左第三任正式女朋友 · **ch16 死**

## 基本档案

- **出处**：《苗疆蛊事》第二卷
- **全名**：江盈美
- **英文名**：无
- **年龄**：19 岁（89 年生，07 年虚岁 19）
- **籍贯**：河南商丘
- **身份**：饰品店店长
- **到南方时间**：15 岁（初中毕业就跟家人闯荡）
- **家庭**：
  - 父亲（老实巴交的农民 / 40 多岁 / 长相老相 / 佝偻 / 眼圈红）
  - 姐姐（已婚 / 丈夫 = 瘦弱的眼镜男 / 姐姐叫陆左"陆老板"→ 死时冷冷看他）
  - 姐夫（瘦弱的眼镜男 / 全程代表父亲和姐姐 / 索赔 100 万）
- **状态**：**已故**（2007-11-21 22:57 被师叔王洛和控制 + 虫瘿致死）

## 视觉

- 美丽 / 青春 / 靓丽
- 鹅黄色短裙装 / 丝袜
- 秀丽的脸上白里透红
- 身材玲珑
- 声音软糯
- 眼勾勾地看着陆左 / 风情万种

### 病态状态（ch16 被虫瘿控制）

- 穿磨砂蓝色牛仔裤 + 粉色羊绒衫 + 浅色小披肩
- 秀美可爱但僵化
- **四肢僵硬 + 头不低 + 走路缓慢一顿一顿**
- 像木偶玩具被操控
- 脸色苍白、僵硬、木然
- **眼睛白多黑少**
- 抿着嘴、嘴角下撇、没血色
- 脸颊靠近耳际的地方有**青黛黑色**

### 死前意识恢复

- 闭着的眼睛缓慢睁开
- 大而无神的眸子（略有些黄）
- 意识游离了一会儿
- 看着陆左
- 柔柔地说："**Who are you?**"
- 嘴唇动了动 → 没说出什么
- 看着陆左 → 有光 → 如星空般璀璨
- 干枯的嘴唇动了动 → 没说出什么

### ch6-13 — 感情线推进

- ch6：饭局 + 拖糖 → 暗示感情

### ch14 — 感情线确立（关键）

- 傍晚小美送银耳莲子羹
- 陆左叫她这几天别来 → 她不理
- 陆左开玩笑："是不是看上那个大老板的小女儿了" → "她的胸可没有你的大"
- 小美脸红 → 转过头不说话
- 陆左觉得太孟浪 → 道歉
- **小美突然问**："**你喜欢我么？**"
- 陆左口结："你这么漂亮，我自然是喜欢的……"
- **小美紧紧抱住陆左**
- 头埋在胸口 → 抽噎着 → 病号服湿了
- 陆左心里柔软
- **陆左的内心**："我想我也应该是幸福的"
- "**然而，人生若能够倒回，我宁愿当时自己狠心，斩断自己、以及小美的情根**"

### ch16 — 被绑架 + 死亡（核心）

- 师叔王洛和电话："**我老婆在他那里**"
- 小美被虫瘿控制
- 陆左用降三世明王心咒 + 金蚕蛊 + 金刚萨埵降魔咒 → 解虫瘿
- **小美死前一刻意识恢复** → "Who are you?"
- 陆左的**第一吻**：印在小美满是血污的额头上
- 小美灵魂离体 → 含笑 → 朝月亮飞去
- **死亡时间**：2007-11-21 22:57

### ch17 — 葬礼 + 赔偿

- 第三天 → 陆左坐轮椅参加小美的葬礼
- 火葬场殡仪馆 → 简陋
- 小美的父亲啐了陆左一脸口水 + 骂很多难听的话
- 小美姐姐冷冷地看着 → 像看一个陌生人
- **姐夫索赔 100 万** → 陆左反驳
- **赔偿**：
  - 12.54 万元（计算公式）
  - 30 万元精神赔偿金
- 小美的父亲带骨灰回河南商丘
  - 埋在向阳的山头
  - 日日看太阳从东边升起，西边落下
