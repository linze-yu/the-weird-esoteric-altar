# 陆左 (Lu Zuo)

> **本命金蚕蛊宿主** · 苗疆蛊事男主角 · 龙老兰的外孙与传人 · 苗疆蛊事第一卷核心蜕变人物

## 基本档案

- **出处**：《苗疆蛊事》小说（南无袈裟理科佛 著）
- **角色定位**：男主角（双男主之一，与萧克明搭档）
- **阵营**：东方神秘组（fog-piercing-forum 圆桌会议席位十）
- **生日**：1986-08-20（农历**七月十五**——鬼节/中元节/盂兰盆节三节合一，最适合做金蚕蛊宿主）
- **教育**：读书早，高中毕业 16 岁，高考落榜
- **籍贯**：湘西（具体 = 大敦子镇，与外婆龙老兰同县）
- **职业**：东莞饰品店老板（合伙人阿根）→ 案件后蜕变为养蛊人 + 神婆传人 + 警方客座奇人

### 打工经历（2002-2007，五年漂泊）

- **地点**：浙江义乌 → 广东佛山/中山/东莞/珠海/深圳 → 合肥（被骗）
- **职业链**：工厂普工 → 领班 → 副主管 → 摆地摊卖水果 → 西式披萨店厨师 → 工地钢筋工 → 保险推销 → 卖家具 → 05 年合肥传销一个月
- **经济起伏**：
  - 最穷：三天只吃两个馒头
  - 最阔：东莞两套房 + 一辆蓝色帕萨特（后转手）
- **2007 年状态**：东莞跟阿根合伙开饰品店，店里十几个人，2007 年混得还行
- **漂泊哲学**："常年待在一个地方、一个小圈子的人是无故事的，只有欲望。但是一个长期在异乡辗转漂泊，见识过人生百态的人，却会有很多的故事。"

## 视觉

- 容貌敦厚，看似不擅言辞的普通青年
- 不起眼到让对手常常忽视
- 吃过苦的人，眼神比同龄人老成
- **第一卷形象弧光**：东莞小老板（1 章）→ 号子里脸黄如金箔、额头游黑纹（2 章）→ 跟警察打成一片的中年酒友（13 章）

## 早期（人格底色）

### 漂泊少年

- 1986 年生，十六岁就出社会
- 自嘲 "比平均的同学要小一到两岁"，并不觉得自己早慧
- 偏远地区小学入学年龄不规范 → 高考懵懵懂懂落榜

### 务实的生存哲学

- "多个朋友多条路，多个敌人多堵墙"（核心信条）
- 吃货本色：馋嘴吃得特别难看 + 猛（打工落魄时养成）
- 自嘲："我这人也好个面子，不想叫人说不爽利，别人敬我我就喝"

### 唯物主义者底色（被命运打碎前）

- "和我许多饱受党国教育的同志们一样，是个唯物主义者，并不认为这个世界上有鬼魂、有僵尸、有乱七八糟的、奇奇怪怪的东西存在"
- 直到 22 岁（2007 年）才被外婆的临终馈赠彻底改变

### 第一次也是最后一次醉酒

- 第一卷第 6 章酒局一斤白酒下肚 → 飘
- **作者明示**："那天晚上是我人生中最后一次醉酒"
- 后续金蚕蛊嗜酒特性 → 陆左酒量大涨

## 关键行为（第一卷完整时间线）

### 第 1 章 — 得蛊（被选中的日子）

- 2007-08-末：东莞饰品店老板 → 接到外婆重病消息
- 卧铺回家 → 破烂出租车 → 第二天去敦寨苗寨
- 外婆清醒问生辰 → "师公，你终于来了"
- 念苗咒 → 金蚕蛊化作金线从手指钻入陆左喉咙
- 外婆第二天死 → 留下《镇压山峦十二法门》+ 遗言："一年内降服不了它，你必死无疑"

### 第 2 章 — 蛊毒发作（与命运签约）

- 初一凌晨蛊毒首次发作：
  - 脸黄如金箔 + 额头游黑纹
  - 腹痛钻心 + 耳聋 + 呼吸困难
  - 持续 10 分钟 + 清醒异常 + 失禁
  - 母亲骂魂："你这个老不死的，连你外孙崽都害"
- **作者原话**："这疼痛应该是分娩的两倍——因为后来我也断过几次肋骨"
- 医院体检 → 一切正常 → 老医师暗示去找龙老兰 → 发现龙老兰就是外婆
- 翻破书找到解蛊法：被矮骡子编戴过的龙蕨草

### 第 3 章 — 寻方（青山界蹲守）

- 去青山界找小叔（县林业局守林员）
- 啃书三天 → 发现《镇压山峦十二法门》= 山阁老著 + 洛十八补注 = 道术 + 巫蛊 + 佛家 + 降头大杂烩
- 准备糯米 + 香烛灰 + 鸡蛋清 + 猎网 + 黄符 + 松子 + 红薯藤
- 蹲守三夜

### 第 4 章 — 抓矮骡子（功德汤代价）

- 凌晨 4 点抓到一只矮骡子
- **李德财发疯**扯断绳网放走 → 小叔被抓 4 道血痕 → 李德财失踪
- 拿草帽回家 → 配功德汤（黑驴黑狗黑猫下宫血 + 朱砂柴胡蟾酥等 + 龙蕨草）
- 敦寨堂庙道场后井水冰镇 → 半夜 12 点喝下
- 狂泻一整夜（黑血 + 虫蜕 + 角质）→ 差点虚脱
- 第四天警察上门 → **案件开启**

### 第 5 章 — 九字真言觉醒（人生分水岭）

- 被传唤拘留 24 小时
- 碎尸案嫌疑大（不在场时段完美重合）
- 号子整夜默念"灵镖统洽解心裂齐禅"
- **作者原话**："那一天晚上，是我人生的转折点"
- **第一次感受到金蚕蛊在左腹肾脏部位呼应**
- 第二天主动找马海波 → 自报龙老兰外孙 → 从嫌疑人变成合作者

### 第 6 章 — 第一次体外下蛊（证身）

- 当面对杨宇（州领导之子）念蛊咒
- 杨宇两分钟后腹痛如绞 → 厕所拉一堆蠕动白虫 → 大男人哭
- 马海波鞠躬道歉："陆先生，对不起……请你不要为难小杨了"
- **陆左的内心蜕变核心**：
  > "我突然就对外婆留给我的东西感了兴趣……有了它，我就不用卑微得跟一个吊丝屁民一样，小心翼翼地生活了，我可以昂着头、挺着胸"
- 给杨宇解蛊（鸡蛋滚胸腹 + 红绳 + 黄符 + 顺便治好脖子神经痛）
- 警局庆功酒局 → 认识马海波 + 杨宇 + **黄菲**

### 第 7 章 — 抹牛眼泪（金蚕蛊直觉觉醒）

- 跟马海波去色盖村勘查
- 路过牲口棚 → **老水牛流泪** → 鬼使神差接牛眼泪抹眼皮
- 第一次看见：
  - 王宝松家黑气腾绕
  - 罗二妹床底凝尸气
  - **青伢子额头凶戾之气**
  - 王宝松头发里满是血腥之气
- **金蚕蛊的本能引导**：心底涌起"去王宝松家"的声音，像刚冒绿芽小心翼翼连接 → 金蚕蛊"认主"标志
- 留 1000 块给王宝松老娘枕头边

### 第 8 章 — 小鬼袭扰（萝莉控自白）

- 疳蛊解蛊：给马海波 + 村干部用鸡蛋滚胸腹
- 半夜遇小鬼（红肚兜粉嫩女娃）
- 默念九字真言 → 抓住 → 问话 → 指向西边罗二妹家
- 鸡叫前放走 → **陆左自白**："我就是个萝莉控，舍不得"

### 第 9 章 — 苗蛊斗法（金蚕蛊首战）

- 警察破门 → 七八条 20cm 五彩蜈蚣伏击 → 两个干警毒发将死
- 陆左当众吐出本命金蚕蛊吸毒 → 又啃蜈蚣尸
- 金蚕蛊自主飞入屋斗罗二妹 → 陆左承认"这小东西根本不鸟我"
- 金蚕蛊从菊花回家 → 陆左泪流满面 → 发誓不让它从嘴里爬
- 罗二妹服输："没想到龙老兰真的练成了本命金蚕，唉，这就是命啊"

### 第 10 章 — 收养小鬼·朵朵

- 挖出小鬼棺材 → 一堆蛆虫 → 陆左连滚带爬吐了
- **小鬼抱腿求收养** → 陆左心软
- 答应带她走 → 寄身处 = 瓷罐娃娃（含头发/骨头/灰/油/膜）
- **小鬼真相** = 黄老牙 6 岁半女儿黄朵朵（被罗二妹下蛊咒死 + 炼小鬼）
- 青伢子定性为罗二妹徒弟 → 当面骂陆左 "苗家的叛徒" + 吐口水

### 第 11 章 — 外婆托梦 + 招魂审讯

- 外婆托梦三件事：① 磕头拜祖 ② 老屋避秽 ③ 书烧掉（"你没能力保护那东西"）
- 敦寨拜祭 → 牌位气旋升起 → 浑身暖洋洋
- 影印店把《镇压山峦十二法门》扫描 PDF+WORD → 254M → U 盘备份 → 烧原书
- **招魂审讯王宝松**：
  - 佛教音乐 + 檀香 + 黄符舌尖血 + 招魂歌
  - **金蚕蛊置幻** = 陆左最强大审讯工具
  - 完整供词：矮骡子让他杀人 → 杀完给金子 → 居所后亭崖子千年古树

### 第 12 章 — 血咒博弈（识破算计）

- 罗二妹托孤：让陆左作见证人 + 仲裁黄家
- 罗二妹对黄老牙下肿蛊（广西壮族特有，困而不死）+ 发血咒
- 解蛊药引：12 只成年母刺猬 + 红糖生姜 + 傍晚吃 + 12 天
- **陆左识破血咒算计** → 拒绝发血咒 → 折中让罗二妹对黄老牙发
- **陆左点破青伢子** = 挖坟制小鬼的执行者
- **青伢子跑了**（案件结束当晚）→ 第二卷伏笔
- 黄菲的感情线：陆左自卑 + 黄菲哭了 → 陆左心软

### 第 13 章 — 返回南方

- 庆功宴 → **陆左让功**给马海波（"多个朋友多条路"）
- **金蚕蛊嗜酒特性发现**：时隔一两天就要喝酒喂蛊
- 李德财在色盖邻村被找到（失忆、虚弱）
- 黄菲两次约咖啡 → 陆左判断她对巫术有兴趣、对陆左只是朋友 → **果断撤退**
- 色盖村取回小鬼乳牙（召回地魂关键）
- 校正《镇压山峦十二法门》电子档
- **带小鬼回东莞**：20 多小时硬卧 → **鬼娃娃帮他捏腿捶肩**

| 维度 | 表现 |
