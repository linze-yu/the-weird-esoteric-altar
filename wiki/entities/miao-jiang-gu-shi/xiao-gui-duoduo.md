# 小鬼·朵朵（黄朵朵）

> **黄老牙小女儿** · 被炼化的小鬼 · 陆左的"鬼娃" · 苗疆蛊事第一卷情感核心线

## 基本档案

- **出处**：《苗疆蛊事》第一卷
- **真名**：**黄朵朵**（活着时）
- **身份**：黄老牙小女儿 → 被罗二妹炼成小鬼
- **年龄**（死亡时）：**6 岁半**
- **现状态**：被陆左收养 → 栖身瓷罐娃娃
- **召回地魂准备**：陆左已取其乳牙（红布包）

## 视觉（深度版）

### 鬼形态（被炼化后）

- **红色肚兜**
- **粉嫩可爱**
- **朝天辫**
- 脸白净得**像瓷器**
- 眼睛**黑黝黝**
- 四肢**雪白、肥嘟嘟**
- 耳后、腭下有**青黑色的狰狞青筋**（被炼化的标志）

### 战斗形态（被陆左抓住时）

- 脸变时：**铁青**
- 眼睛变：**红色**
- 嘴裂成**满是厉齿的大嘴**
- 一口咬陆左胳膊 → 被金蚕蛊热力烫

### 屈服后

- 眼睛变**黑色**
- 有点亮光（像黑夜中的灯光）
- 可怜巴巴地看着陆左
- 眼睛会眨

### 讨好表现（求收养时）

- 找笤帚扫地
- 拿着陆左的衣服揉
- 看陆左没反应 → **着急得直哭**
- **小鸡啄米一样点头**

## 来源（深度版）

### 活着时

- **黄老牙的小女儿**（6 岁半）
- 黄家是县城数得上的富豪之家
- 黄老牙仗势欺人 → 得罪罗二妹的儿子 → 罗二妹报复

### 死因

- 离奇死亡：**双眼翻白、口吐黑血**
- 医院诊断无病无灾，突然连病数日
- 死后**尸体被盗**（罗二妹指使青伢子挖坟）

### 被炼化过程

- **炼制方法**：
  - 打开刚死孩童的墓地
  - 用蜡烛烧烤童尸的下巴
  - 用小棺材接尸油
  - 用尸油直接炼制小鬼
- **炼制者**：罗二妹（主谋）+ 青伢子（14 岁徒弟执行）
- **炼制完成**：灵体成形 → 可派出去作祟

### 小鬼的来源（罗二妹点破）

> "后生仔，看来你真的是龙老兰的外孙了。"
- 罗二妹亲口承认小鬼是从黄家"做孽"那里找的 = 黄老牙小女儿黄朵朵
- "至于是哪里找的？谁做孽就在谁那里找的呗"

## 能力（深度版）

### 小鬼通用能力（《镇压山峦十二法门》躯疫章）

- **聚财**（小鬼通用）
- **消灾**（小鬼通用）
- **警兆**（小鬼通用）
- **迷幻**（小鬼通用）
- **护宅**（小鬼通用）
- **害人**（小鬼通用）

### 朵朵的具体能力

- **吹冷风**（脖子后嗖嗖凉）
- **迷惑**（让王宝松杀人）
- **能听懂人话**（无舌头不能说话）
- **求助表达**（指东西 + 点头摇头 + 哭）
- **屈服后帮人**（捏腿捶肩）

## 性格演变（深度版）

### 早期（被罗二妹控制）

- 被罗二妹控制，被迫害人
- 工具属性 → 不表达自身意愿

### 中期（ch8 陆左第一次遇）

- 恐惧地看着陆左
- 嘟嘴吹气 → 脖子后面嗖嗖凉
- 害怕 → 想跑 → 被抓住
- **屈服后** → 可怜巴巴看着陆左
- 眼睛眨 → 表示有智慧

### 后期（ch10 求收养）

- **会扫地**（找笤帚）
- **揉衣服**（讨好）
- **着急得直哭**（求收养）
- **小鸡啄米一样点头**（答应条件）

### 现在（被陆左收养后）

- 栖身瓷罐娃娃（陆左随身带）
- **火车上帮陆左捏腿捶肩**
- 召回地魂后可重开灵智 → 避免异化为邪物

## 关键事件（按章节）

### ch7 — 伏笔（黄朵朵离奇死亡）

- 黄老牙小女儿 6 岁半
- 离奇死亡：双眼翻白、口吐黑血
- 死后尸体被盗
- 老板老婆觉得蹊跷 → 报警
- 黄老牙反对验尸 → 拗不过老婆 → 同意 → 尸体已盗

### ch8 — 小鬼第一次出现

- **2007-09-XX 深夜**：
  - 陆左在专案组驻地睡觉
  - 脖子后面嗖嗖冷风（像风油精+山风）
  - **红色肚兜粉嫩女娃** → 朝天辫 → 白瓷脸 → 黑眼睛 → 雪白肥嘟嘟
  - **耳后腭下有青黑色狰狞青筋**（被炼化标志）
  - 嘟嘴吹气 → 脖子后面嗖嗖凉
- **陆左认出**：小鬼（《镇压山峦十二法门》躯疫章）
- **应对**：
  - 默念九字真言 → 脖子凉意消散 → 灼热气流从小腹升腾
  - 跳下床抓住女娃
  - 她咬陆左胳膊 → 被金蚕蛊热力烫
- **问话**：
  - "是谁派你来的？" → 鬼娃恐惧地看向**西边（王宝松家）**
  - "你会不会说话？" → 摇头
- **放走**：村子里鸡叫第一遍 → 灵体惧阳光 → 陆左心软放走
- **陆左自白**："好吧，说了这么多，其实我就是**个萝莉控**，舍不得"

### ch10 — 求收养

- 警察逮捕罗二妹 + 王宝松
- **罗二妹床上挖出小棺材**（陆左指定挖掘位置）：
  - 50 公分长度薄皮棺材
  - 腥气冲天
  - 打开后：灰白骷髅架子 + 烂肉化肉泥血浆 + 无数白色蛆虫
  - 陆左 + 几个警察连滚带爬吐了
- **小鬼出现** → 粉雕玉琢的小女孩抱着陆左腿
- **问答过程**：
  - "你要干什么？" → 摇头 → 指着小棺材
  - "你是要我帮你埋葬好？" → 摇头
  - "你是要我帮你超度亡灵？" → 摇头 + 拼命摇头 + 惊恐
  - "你不会是要我带你走吧？" → **终于点头 + 讨好笑容（像讨好主人的小狗）**
- **收养条件**：
  - 陆左为难："我一个大男人带着个小鬼算怎么档子事？"
  - 小鬼卖力讨好（扫地 + 揉衣 + 着急哭）
  - 陆左心软："她小小年纪惨遭横死，被人炼尸控制来害人，本身蛮可怜的"
- **收养仪式**：
  - 小鬼指向**神龛上的瓷罐娃娃**
  - 陆左拿瓷罐 → 脖子附近有开关 → 内有小空间（头发、骨头、灰、油 + 一层膜）
  - 陆左条件："你要是不听话，我就把你丢到太阳下面去晒。"
  - 小鬼吓直摇头 + 小鸡啄米点头
  - **小鬼化成白线钻进瓷罐**

### ch11 — 外婆托梦（召回地魂法）

- 罗二妹临终传授陆左："召回小鬼的地魂（又为识魂），唤醒记忆，重开灵智。"
- **召回地魂的意义**：
  - 避免小鬼时间久了 → 善妒、记仇、暴戾、懵懂 → 异化为邪物 → 心智全无
  - 重开灵智 → 自己的意识、世界观 → 方有所成就
- 陆左同意 → 罗二妹发血咒

### ch13 — 取乳牙 + 带小鬼回南方

- **陆左去色盖村取回小鬼乳牙**（红布包）
- 召回地魂的关键
- **回东莞火车上**：20 多小时硬卧 → 鬼娃娃帮陆左捏腿捶肩
