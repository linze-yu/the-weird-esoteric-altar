# 罗二妹 (Luo Ermei)

> **色盖村养蛊人** · 碎尸案幕后主使 · 小鬼炼化者 · **牺牲自己成全儿子的母亲**

## 基本档案

- **出处**：《苗疆蛊事》第一卷
- **身份**：养蛊人 / 黑巫术师 / 小鬼炼化者
- **苗名**：罗二妹
- **出身**：**钟仰苗寨**（极为偏远的生苗寨，常年不跟外界往来，养蛊风气极盛）
- **嫁入**：色盖村（嫁到色盖村一辈子没人知她养蛊）
- **家庭**：
  - 丈夫已故
  - 儿子 **[[王宝松]]**（已疯）
- **状态**：**病入膏肓**（瘫痪在床，临终前数日）
- **结局**：第一卷末尾病重（未明确死亡日期，但已近死期）

## 视觉（深度版）

- 形容枯槁
- **瘦得跟木乃伊**
- 身上全部都是骨头
- 脸十分恐怖
- 眼睛混浊、满是眼屎
- **棕红色毛线帽**（卧床时戴）
- **瘫痪在床**（无法行走）
- **嘴里无牙**
- 笑得很诡异
- **滴腥臭的水**（被抬出时）

### 养蛊代价（典型）

- 阳气被夺
- 气运侵蚀
- 容貌恐怖
- 命格不得善终
- **陆左判断**："这些特征都一致"

## 能力（深度版）

### 核心能力

- **养蛊**：金蚕蛊（间接） / 疳蛊 / 肿蛊 / 蜈蚣 / 阴蛇蛊等
- **炼小鬼**：开童墓 + 烤童尸 + 接尸油
- **下蛊**：黄老牙（肿蛊）
- **血咒**：以血为导引的契约咒
- **御兽驱虫**：能放出蜈蚣
- **灵魂沟通**：与蛊对话
- **苗话念咒**：能跟陆左以苗话交流
- **中仰苗寨传承**：从钟仰苗寨所学（但传承已丢）

### 养蛊人典型代价

- 阳气被夺 → 气运侵蚀 → 容貌恐怖 → 命格不得善终
- **陆左感叹**："以前书上看终觉得不信，今日一见，心中更寒"

## 人生轨迹（深度版）

- 出生钟仰苗寨（养蛊风气极盛）

- 警察破门 → 七八条五彩斑斓蜈蚣伏击 → 两个干警毒发将死

### ch10 — 逮捕 + 真相

- 罗二妹被抬出（被子裹着 + 脚滴腥臭的水）
- **罗二妹亲口承认**：
  - "她笑得很诡异"
  - "真的是青出于蓝啊"
  - 主动承认小鬼 + 床下埋着
  - "至于是哪里找的？谁做孽就在谁那里找的呗"（暗示黄朵朵）
- **指认青伢子**："是青伢子帮你去下的蛊吧……这小鬼现在才十四岁吧，胆儿挺大的！"
- 罗二妹不回答 → 闭上眼睛

### ch11 — 招魂审讯王宝松

- 王宝松招供"山神爷爷" = 矮骡子
- 矮骡子住后亭崖子千年古树
- 矮骡子让王宝松杀人 → 杀完给金子
- 罗二妹 = 案件核心 = 矮骡子的"中介"或"共谋"

### ch12 — 临终托孤

- 陆左去重症监护室见罗二妹
- 罗二妹要求陆左**做见证人**：
  - 罗二妹承认咒死黄朵朵 + 藏尸
  - 对黄老牙下肿蛊
  - 血咒绑定黄家
  - **目的**：以死换儿子未来
- 罗二妹传授**召回小鬼地魂**之法
- **血咒博弈**：罗二妹想让陆左发 → 陆左识破 → 折中让罗二妹对黄老牙发

### ch12 — 解肿蛊药引

- 找齐**12 只成年母刺猬**
- 每日一只，熬煮红糖生姜
- **傍晚吃下**
- **连续十二天**，不能多也不能少

## 真实目的（陆左分析）

> "她嫁到色盖村，一辈子都没有给人知道是个养蛊人、神婆，此次出手，根本就是想要**牺牲自己，成全儿子**。"

**罗二妹的真正目的**：
- 50 万 → 儿子王宝松治疗
- 送州精神病院
- 承担后续费用
- **自己的命换儿子的未来**
