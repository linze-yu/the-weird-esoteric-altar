# 外婆·龙老兰 (Long Lao Lan)

> **苗寨神婆** · 陆左外婆 · 金蚕蛊炼制者 · 苗疆蛊事第一卷核心已故人物

## 基本档案

- **出处**：《苗疆蛊事》第一卷
- **身份**：苗寨神婆 / 养蛊人 / 看香 / 算命 / 治病 / 驱鬼 / 看风水
- **状态**：**已故**（2007-08-末，外婆下蛊次日死亡）
- **享年**：80+ 岁
- **出生地**：与陆左母亲相同（具体待补）
- **居住地**：湘西苗疆敦寨（生活了 86 年）
- **师承**：深山苗寨男神婆（已故，死时肠子被野狗拉 5 米，爬满蛆虫）
- **称号**："先生"级（湘西圈子里响亮名字，警局都敬畏）

## 视觉

### 健康时（年轻时）

- 十里八乡的美人
- 经历变故后跟深山苗寨男神婆学巫术

### 病重时（陆左探病时）

- 枯瘦的小老太太
- 不苟言笑
- 鹰钩鼻，嘴巴无牙
- 脸塌了一边
- **临终时**雪白头发，皮肤如老松树皮，一脸黑黄色老人斑
- 偶尔清醒时**两眼有神**（陆左描述："突然之间，外婆的眼睛亮了起来"）

### 临终清醒时

- 咳嗽后吐出**浓浓的黑痰**
- 突然能下床（回光返照）
- 颤颤巍巍走到茶几前
- 咕哝着苗话
- 手指颤抖挥舞（10 分钟下蛊仪式）

## 能力（深度版）

### 核心能力

- **养蛊**：炼制金蚕蛊几十年（本命蛊）
- **巫术**：能召唤**金蚕蛊进入人体**（陆左案例）
- **算命**：看香，能断人生（"你良如玉石需磨难，需到外面的世界受点苦"）
- **治病驱鬼**：十里八乡尊敬
- **托梦传遗言**（死后）
- **历史战绩**：
  - 1950 年湘西剿匪：18 个土匪死于恶疾，尸体涌出数百只虫
  - 体内蛊虫火化后心肝呈**蜂窝状**
- **拜祖仪式控制**：陆左拜祖时神龛牌位有气旋升起 → 通体舒透
- **避秽：** 老屋院子里土地下埋着无数虫尸长蛇
- **仪式控制**：外婆一声令下全家照做（小舅挖坑、母亲烧纸、亲戚聚集）

### 苗疆巫术分类（《镇压山峦十二法门》作者对照）

- 巫医 / 育蛊 / 符箓 / 禁咒 / 祀神 / 占卜 / 躯疫（7 大类）
- **圆桌化对比**：
  - 跟陆左的苗医 / 育蛊 / 躯疫 / 祀神（陆左传承 4 大类）
  - 跟萧克明的符箓 / 禁咒（茅山正宗）

## 人生轨迹（深度版）

- **年轻时**：十里八乡的美人 → 经历变故 → 跟深山苗寨男神婆学巫术
- **师父死后**：传承断代 → 自己成了苗寨神婆
- **1950 年**：18 个土匪死于恶疾（湘西剿匪历史战功）
- **1950-1970 年代**：依然在十里八乡看香 / 治病 / 驱鬼
- **1970-1980 年代**：行政下乡 + 寨子与外界联络渐多 → 淡出外人视野
- **晚年**：一个人在敦寨苗寨里住着 → 精神一向好 + 村子里的人帮忙照顾
- **2007-08-末**：胃癌晚期 → 下金蚕蛊 → 死亡

## 关键事件（按章节）

### 第 1 章 — 临终下金蚕蛊

- **2007-08-末**：陆左接到外婆重病消息 → 赶回湘西
- 外婆浑浑噩噩两天（神志不清）
- **清醒瞬间**（关键转折）：
  - 表嫂通知 → 陆左进卧室
  - 外婆问生辰："你是陆左？你是什么时候生的？"
  - "8月20号，农历七月十五。" → **外婆眼睛亮了**
  - 大声咳嗽 → 吐出**浓浓的黑痰**
  - **"师公，你终于来了。"**（作者注释 = 外婆一直在等农历七月十五出生的外孙）
- **下蛊仪式**：
  - 外婆突然精神好转，能下床
  - 指挥小舅到屋后空地挖一小罐泥坛子（早先做雨伞的厚油纸封口）
  - 同时挖出木匣（《镇压山峦十二法门》手抄本）
  - 外婆咕哝苗话 + 手颤抖挥舞（10 分钟）
  - **蚕蛹化作金线钻入陆左喉咙**
  - 陆左昏迷

### 第 1 章 — 临终遗言

- 次日外婆去世，走得很安详
- **遗言 5 件事**：
  1. 金蚕蛊可延年益寿、强身健体
  2. 但有毒性 → **每月初一/十五凌晨 12 点钻心疼痛**
  3. 解毒方法 → **矮骡子编戴过的龙蕨草**
  4. **一年之内**降服不了金蚕蛊 → 必死
  5. 留下《镇压山峦十二法门》作为传承

### 第 11 章 — 托梦传遗言

- **梦境情境**：真实得不像话
- 外婆动作：宽慰地看陆左 + 摸头
- **遗言 3 件事**：
  1. **回敦寨老屋磕头拜祖**
  2. **老屋里所有东西避秽不取**
  3. **《镇压山峦十二法门》书烧掉**（"你没有能力保护那东西"）
- **关于中仰苗寨**："中仰苗寨的人，传承早就丢失了，没了……唉！"
- **关于本脉**："我们这一脉也快没了。"
- **临终叮嘱**："**积德行善，好自为之。**"
