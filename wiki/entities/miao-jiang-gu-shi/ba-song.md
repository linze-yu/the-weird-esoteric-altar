# 巴颂

> **泰国降头师** · 洛十八第七弃徒之徒 · 第六卷核心反派

## 基本档案

- **出处**：《苗疆蛊事》第六卷
- **身份**：段叔请来的私人顾问 + **降头师**
- **师傅**：洛十八的第七个弟子（被逐出门墙的弃徒）
  - 当年也是一天资卓绝之辈
  - 不忿于师傅的保守不通达
  - 南下寻求证道之法
  - 落根泰国 + 开枝散叶
- **王洛和的生死之交**
- **状态**：**已死**（被萧克明的雷光疾电符 + 三茅真君斩杀）
- **本命神器**：无 + 多个控尸降本物 + 控魂降 = **复合降头师**

## 视觉（伪装状态）

- 黑瘦 + 像黄皮猴子
- 头发稀疏
- 耳朵上至少 **10 个以上的耳环**
- 脖子纹有花纹（**两侧的眼睛尤其传神**）
- 看一眼心惊胆颤 → 仿佛看透人心

## 视觉（真实状态 - 拙火瑜伽变形后）

- 身高从不到 1 米 7 变 **1 米 9 高大汉子**
- 全身纹身活过来 → 毗湿拏座下的恶鬼形象
- 黑雾包裹 + 像魔王出世
- 双目红 + 黑白颠倒
- 十对眼睛（从小到大）+ 直视人心

## 性格

- 阴测测 + 高高在上
- 掌握一切主动权
- 笑的方式很残忍
- 舌头像蛇 + 舔着鼻尖
- 用食指勾引挑衅
- "**萤火岂敢与日月争辉**"
- 看人如看蝼蚁

## 战斗能力（七种降头术）

### 1. 控魂降

- 通过鸦片膏作为药引
- 强制吸食 → 上瘾 + 减低防备
- 借机控制心神
- **特效**：可以隔着空间控制被引子影响的人

### 2. 控尸降（洛十八徒弟发明）

- 找一个生辰八字 + 命理都合乎准则的人体
- 用相应方法将炮制死亡
- 用特殊手法炼制
- **施术者必须在百步之内**，法力最强者也不能超过**两百步**
- "**附念头到起身上，多了一道强力的攻击手段**"
- **美人头颅**：四颗尖锐的牙齿 + 一指长 + 头发如弹簧 + 拖着血淋淋的肠子 + 悬浮 + 笑

### 3. 蜈蚣降

- 长条节指硬壳 + 第一对脚呈钩状 + 锐利
- 牙爪毒肢 + 节肢
- 十几公分长
- **4-5 个篮球大小的蜈蚣团**
- 黑色、红色、黑绿色
- **毒性**：普通同类百倍千倍 + 中毒即死

### 4. 水草鬼 / 河童 / 水虎 / 水精

- **80 公分到 1 米**
- 像人又像猴子
- 黑色毛 + 全身黏嗒嗒
- 暗绿色 + 鱼虾水草腥臭
- 背乌龟壳 + 脸长鸟嘴
- 披头散发 + 头部凹陷处
- 暗红色眼睛 + 嗜血残忍
- **四把镰刀武器**
- "**如果在脑门的凹陷处盛满水，便力量无穷，可撕牛裂马**"

### 5. 恶鬼古曼童（3 只）

- 红眼睛
- 十字口器
- 森森交错尖牙
- 灵力咬出血淋淋的伤口

### 6. 请神降 / 请神

> "**以请神为降，以头祭之。这是一门不计入正史的恐怖降头术，只在少数降头师圈子中做流传，隐秘**"

- 与所请的神灵（也许是魔鬼）**作交易**
- 以自己**数年的生命为代价**
- 获得力量 → 杀死对手
- 这门降法与**猿尸降**一样，最开始都是原始宗教为显示神迹
- "**它并不属于降头术的一门分类，而属于白巫术的范畴**"
- **真实历史**：炼制大成的一个没有

### 7. 尸精散

- 黑色晶状矿物 + 像蟑螂屎
- 与无垢泥 + 毒蛇囊 + 蜈蚣腿等物混合炒制
- 黑色晶状矿物 = 灵魂沉积的寄托体
- 最好的黑巫术、邪法等的增幅佐料
- "**比金蚕蛊这种半调子增幅器，要好用十倍以上**"

> "**许邦贵这龟儿子就是个弑师的逆徒，他的余脉，何德何能，能够安享本命金蚕蛊的培育之法？**"
