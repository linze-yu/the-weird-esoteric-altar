# 加藤原二

> **17 岁混血儿** · 柔道高手 · 加藤一夫儿子 · 第四卷大反派

## 基本档案

- **出处**：《苗疆蛊事》第三卷
- **身份**：日本少年 + 加藤一夫儿子 + 第四卷大反派
- **年龄**：不超过 17 岁
- **身高**：1 米 6
- **身体**：瘦弱
- **视觉特征**：
  - 瞳孔呈**淡蓝色**
  - 轮廓偏西方
  - **混血儿**
  - 跟旁边膀大腰圆的西装形成鲜明对比
- **气质**：从偶像剧和漫画里走出来的人
- **眼神**：淡淡忧伤 + 逆流成河的悲伤

## 视觉（ch13 首次登场）

- 穿着西装革履 + 皮鞋飒亮
- 跟着一群趾高气扬的日本人
- 灰白头发的加藤一夫 + 翻译
- 旁有"砰砰保镖们"

## 性格

- **柔弱** + **倔强** + **孤傲**
- **心狠手辣**：用枪逼壮汉进玻璃罩房 + 喷雾剂 + 眼睛不眨
- **柔中带狠**：跟陆左扭打时柔道高手 + 3 下两下按倒陆左
- **出言不逊**："**或许吧，这么弱的家伙，怎么可能成为我想象中的对手呢？我高看你了**"
- 喜欢"骂人"：陆左挣扎时说"**该死魂淡**"（巴格牙鲁）

## 战斗能力

- **柔道高手**：跟陆左扭打 + 3 下两下按倒 + 关节都用不了力
- **"脱北者"（朴志贤）级武力**：像专业训练过的人
- **灵敏性**：像黑猫般灵巧
- **冷静**：用枪威胁 + 眼睛不眨

## 关键事件（按章节）

### ch9 — 夜闯植物园（首次正式登场）

- **1 米 6 + 穿黑 + 蒙面 + 身体柔软如黑猫**
- 用日语骂 + 用军刀斩断藤蔓
- 掏出喷雾剂让藤蔓缩回去
- **踹门进玻璃罩房** + 掏出更大的喷雾器
- **掏枪** → 让壮汉进玻璃罩房拿**笸箩竹笼花的红色果实**
- 壮汉"被他喷洒得几近融化"（白色雾气像硫酸）

### ch13 — 白天正式登场

- 跟在加藤一夫旁边
- 看到陆左 + 萧克明 → 走过来打招呼
- "**你好，我叫做加藤原三，初次见面，请多多关照**"（自我介绍名 = 加藤原三？待补）
- 陆左的判断：跟 ch9 夜闯植物园的日本人是同一人

### ch14 — 结下仇怨

- 出包厢门口拦陆左
- 冷冷盯着陆左
- "**你到底拿没拿龙血还魂草，拿了，赶紧给我，我给你钱，两百万！怎么样，中国人？这草，我要来救琴绘姐姐的性命的。**"
- 陆左："**滚球去**"
- 挣扎 → 重心一偏 → **被小个子一下子摔了出去**
- 陆左跳起来 → 扭打 → **加藤原二是柔道高手 + 3 下两下按住**
- 陆左脸贴地 + 动弹不得 + 憋屈得想发疯
- **无金蚕蛊的窘境**："**用不了金蚕蛊的力量了……我变成了以前的那个废材**"
- 萧克明从后面掐脖子 + 一牛之力按在地板砖上
- "**骂了隔壁的，你这个小日本子敢打我家兄弟！不想活了？**"
- 加藤原二放开 → "**或许吧，这么弱的家伙，怎么可能成为我想象中的对手呢？我高看你了**"
