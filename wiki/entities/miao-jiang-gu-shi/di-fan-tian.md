# 地翻天 / 王三天

> **王氏大屋反派转中立** · 楚巫祝由一派 · 尸丹高手 · 五鬼搬运术

## 基本档案

- **出处**：《苗疆蛊事》第五卷
- **身份**：湘西凤凰天龙峡附近村子的土夫子头领
- **姓名**：王三天
- **别名**：地翻天
- **家族**：王家 15 口人（太爷爷 + 地翻天 + 2 个弟弟 + 3 闺女 + 1 小儿子 + 媳妇）
- **职业**：**尸丹高手** + 五鬼搬运术 + 团伙型土夫子

## 视觉

- 瘦小 + 一脸精明
- 像乡干部 + 两撮小胡须
- 脸色白皙 + 脸颊上有几颗细碎的麻子
- 眼睛灵活 + 眼珠子一骨碌

## 性格

- 初见：**冷淡 + 审视 + 不耐烦**
- 听完陆左讲朵朵：留饭 + 给法门
- "**江湖人，闯荡四方，讲究的就是个招子敞亮**"

## 战斗能力

### 五鬼搬运术（看家本领）

- 一串黄黑色的光洁珠子（像玛瑙 + 像琥珀）
- 念非汉非苗的经文
- 五团黑影 = 木鬼（驯服 + 受制符箓）
- **能缠人 + 不拘百里 + 都能害人致死** = 求财

### 王家炼尸

- 太爷爷 100 多岁 = 服尸丹长寿
- **十二尸巫**（地窖藏尸 + 王家传承）
- **小黑天**（**尸宝** + 跳尸 + 帮陆左 + 一掌拍飞好几头同类）

### 王家地窖 + 尸阵

- 地窖 = **藏尸的储藏室**
- 僵尸：四肢僵硬 + 死后很久不腐烂
- 赶尸的炼尸：辰砂置七处 + 神符压住 + 五色布条绑紧 + 朱砂塞耳/鼻/口
- 僵尸来源：**墓里翻出来** + **火葬场狸猫换太子**

### 王家"五道杠"小儿子

- **王永发**（7-8 岁）
- 像"五道杠"
- 见过陆左很老成的样子

## 关键事件（按章节）

### ch5 — 初见

- 王永发接陆左到王家大屋
- 地翻天冷淡 → 审视 → 不耐烦

### ch6 — 老太爷识破 + 五鬼搬运展示

- 老太爷看穿陆左农历七月十五
- 五鬼搬运术展示 → 五团黑影
- 陆左伸手去捉 → 地翻天拉住 → "**你的双手，既遭阴物忌恨，又是能够伤害到阴物的东西**"

### ch7 — 尸坑暗算（核心）

- 王永发掉地窖 → 地翻天的交易（救儿子 = 法门）
- **正月初六 → 毛上臭 → 大害**
- **十二尸巫**从地窖蹦出 → 陆左 + 金蚕蛊救援 + **炁之感应觉醒** + **王冠肉茧** + 跳尸叛变

### ch8 — 给《鬼道真解》

> 「**这卷帛，是我爷爷与几个同行在解放前，从明代一个白莲教楚南舵主的葬墓里面，翻出来的**」

- 《鬼道真解》丝帛 → 三章 → **空灵章节 2320 字**
- "**这里面，有三魂还剩两魂的鬼魂修炼的法门**"

### ch8 — 王家十二尸巫损失

- 跳尸帮陆左拍飞好几头同类
- 一头被拍裂 → 碎成六七块腐臭肉块
- 王家**十二尸巫损失了 6 成**
- 络腮胡子老弟的散弹枪 + 黑血 + 红绳 + 符箓
