## 关键记载（陆左实际使用）

### ch2 — 金蚕蛊解法

- **金蚕蛊的炼制法**：
  - 端午三天内抓 12 种毒虫
  - 密封一年
  - 自相残杀
  - 毒多吃毒少
- **本命蛊**：外婆炼制了几十年
- **解法**：矮骡子编戴的龙蕨草

### ch3 — 矮骡子抓捕法

- **山魈记载**：
  - 30-50 cm
  - 戴红草帽（龙蕨草编）
  - 怕金蚕蛊
- **抓捕法**：
  - 新糯米（鸡蛋清 + 香烛灰）
  - 猎网
  - 蹲守深山老林

### ch4 — 功德汤配方

- **解蛊药方**：
  - 黑驴、黑狗、黑猫的下宫血
  - 朱砂、柴胡、蟾酥锭、紫雪、琥珀、蚕茧、牛黄、全蝎、胆南星
  - **龙蕨草**（矮骡子编戴过的）
  - 煮三天三夜
  - **敦寨堂庙道场后井水冰镇**
  - **半夜十二点喝下**

### ch6 — 解蛊 + 治杨宇

- **蛊毒吸蛋黄法**：
  - 刚下的土鸡蛋（最新鲜）
  - 红线捆住手腕脚踝
  - 用力拍打
  - 泡好的鸡蛋滚胸腹
  - 黄符烧灰
- **意外**：脖子神经痛治好（巫医的真传）

### ch8 — 疳蛊解法

- **疳蛊配方**：
  - 蜈蚣 + 小蛇 + 蚂蚁 + 蝉 + 蚯蚓 + 蚰蛊 + 头发
  - 研末为粉
  - 房内或箱内所刻五瘟神像前供奉
  - 久之，下在水里
- **症状**：肚胀、叫痛、欲泻、上下冲动
- **陆左应用**：用鸡蛋滚胸腹 + 黄符烧灰

### ch8 — 小鬼记载（躯疫章）

- **小鬼的体系**：
  - 茅山术：养五鬼、柳灵童子
  - 东南亚：养古曼童
  - 苗疆：养小天童
- **炼制法**：
  - 打开刚死孩童的墓地
  - 蜡烛烧烤童尸下巴
  - 小棺材接尸油
  - 尸油直接炼制
- **小鬼的用途**：聚财 / 消灾 / 警兆 / 迷幻 / 护宅 / 害人
- **小鬼怕光**：见光即消融 → 必须寄身于炼化物中

### ch11 — 招魂术 + 九字真言

- **降三世明王心咒**：灵镖统洽解心裂齐禅
  - 灵：身心稳定
  - 镖：能量
  - 统：宇宙共鸣
  - 洽：自由支配
  - 解：危机感应
  - 心：心电感应
  - 裂：时空控制
  - 齐：使万物平齐
  - 禅：佛境
- **苗话 / 金陵官话**皆可念
- **使用场景**：
  - 默念整夜 → 第一次感应金蚕蛊
  - 默念 → 灼热气流从小腹升腾 → 抓住小鬼
  - 默念 → 招魂审讯王宝松

### ch11 — 招魂歌

- 陆左招魂王宝松时唱：
  > "三魂丢兮哟难找回，一心游离外，两魄不足惜，昨天吃油茶，今天把魂丢，魂掉不止尽，下生不安宁，魄归兮哟魂归来……"

### ch11 — 召回小鬼地魂法

- **召回地魂**（又为识魂）= 唤醒记忆 + 重开灵智
- **避免小鬼异化**：
  - 时间久了 → 秽阴之气洗涤心智
  - 善妒、记仇、暴戾、懵懂
  - 异化为邪物 → 心智全无
- **需要的材料**：
  - **小孩子乳牙**（陆左已取朵朵的）
  - **红布包好**
- **召回后的好处**：
  - 自己的意识 + 世界观
  - 方有所成就
  - **作为主人也会水涨船高**
