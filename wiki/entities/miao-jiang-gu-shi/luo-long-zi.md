# 罗聋子 / 罗大成

> **中仰苗蛊一脉传人** · 罗二妹堂兄 · 第四卷反派

## 基本档案

- **出处**：《苗疆蛊事》第四卷
- **身份**：中仰苗蛊一脉 + 罗二妹堂兄 + **第四卷反派**
- **姓名**：罗大成
- **别名**：罗聋子（外号）
- **状态**：**已死**（钉蛊反噬）
- **出生地**：中仰村七组螺蛳坳
- **伪装**：罗老爹（瞎眼 + 泡蜂糖罐水）
- **绝学**：钉蛊（二十二日子午断魂钉）

## 视觉

- 佝偻着身子
- 抽旱烟 + 红色火星子
- 瞎了半只眼睛（**伪装**）
- 搬矮板凳过来

## 性格

- **歧视汉人**："**中国人是汉族的事情，汉人家衙门的事情**"
- **讲蛊**："**恩要报仇要清**"
- **临死狂言**："**二妹栽于你手，我栽于你手，不过你不要得意，你不要以为我们中仰苗蛊一脉就这样消亡了**"
- 心里明白陆左说得对 → 但依然执着
- "**恨也许是支撑他活下去的最大动力**"

## 战斗能力

### 疳蛊

- 配方：蜈蚣 + 小蛇 + 蚂蚁 + 蝉 + 蚯蚓 + 蚰蛊 + 头发
- 研末为粉 + 置于房内或箱内所刻的**五瘟神像前**
- 供奉久之而成为的毒药
- 中者鼓胀 + 腹泻 + 虚弱至奄奄一息

### 灵蛊（绝学）

> "**他罗聋子这一辈子，最擅长的不是这些药蛊，而是灵蛊**"

### 钉蛊（二十二日子午断魂钉）

- 用一根生锈的铁钉
- **日夜供奉神像之前**
- 逢初一十五不食水米
- 年年吃斋
- 念二十年经换来的
- **意念一达** → 铁钉就入体
- 过谷道 + 钻小肠 + 五脏六腑游览遍
- **最后从双眼之中透体而出**
- 历时二十二天 → 最终死亡

### 反噬

- "**用念力下蛊害人，人若不中招，施术者必中反馈，生生承受这一拳打空的力道**"
- 陆左中疳蛊未发作 → 罗聋子脚下**一滩血迹**（自身反噬）

## 关键事件（按章节）

### ch4 — 李大伯讲述罗聋子前史

- 2 个月前来陆左家附近
- 想朝陆左家使坏
- 李大伯拉住 → "**你把他堂妹子送到了局子里，死了都没得善终**"
- 罗聋子："**要搞搞你家**"
- 陆左家外婆布置的清光镜、纹路棍让他退去

### ch7 — 进山途中下疳蛊

- 在中仰村七组最后一户作伪装
- 泡蜂糖罐水 → 看似甘甜
- 陆左喝水时"**背上不舒服，像被蛇爬过一样，冰冷，油腻腻的**"
- 陆左没发作（因为有金蚕蛊底子）

### ch15 — 大黑天魔王召唤 + 钉蛊

- 描述夜郎国 / 耶朗 / 矮人国
- 自报家门 = **罗大成，罗聋子**
- 解释动机：**罗二妹堂兄**
- 用**灵蛊** → 下**钉蛊**

### ch16 — 罗聋子临死

- 被陆左扇耳光
- 被陆左王八拳
- 钉蛊发作 → 自己反噬
- 死前狂言
- **王万青伏笔**

## 钉蛊失败 + 洛十八传承

### 罗聋子下钉蛊

- 大喝"**度**"
- 陆左屁股下面的凳子突然抖动
- 尖锐之物攻入陆左体内
- 朵朵救场（咬罗聋子后颈）

### 钉蛊发作 + 罗聋子识破陆左

- 罗聋子大呼："**破，钉子破，生魂开，七十二路神仙爷爷奶奶，让他死吧！**"
- 陆左体内炸响 → 通体生疼 → 集中到丹田
- "**一个庞大的意志连接到了我的脑海里**"
- **罗聋子失魂**： "**你……你居然、居然是汉蛊王洛十八的……**"
- **陆左昏迷 3 天**
- 罗聋子被钉蛊反噬 → **快挂了**
- 县里准备追悼会 + 罗聋子自己死
