# 矮骡子头人

> **矮骡子头人** · 第一卷被陆左抓到 + 第四卷被陆左掐死 · 矮人国伏笔

## 基本档案

- **出处**：《苗疆蛊事》第一卷 + 第四卷
- **身份**：青山界矮骡子头人
- **身高**：40 公分
- **状态**：**已死**（被陆左掐死）
- **出生地**：青山界后亭崖子千年古树溶洞
- **武器**：红色草帽 + 紫红色眼睛 + 蓝血 + 灵体 + 召唤毒虫

## 视觉

- 四十公分高
- 脖子细长
- 皮又粗又黑 + 全是虫茧
- 温热的感觉
- **红色草帽**（标志性）
- **紫红色的眼睛** → 像灯泡
- **蓝色血浆**（腐蚀性）
- 黑色癞皮

## 战斗能力

### 幻术

- 最厉害的能力 = **幻术**
- 把一坨牛粪变成金子（让王宝松到黄老牙的店子里卖）
- 迷惑李德财解开猎网袋、杀人
- 让人到"地仙界"（石桌石椅石床 + 仙女伴床 + 美食佳酿 + 酒池肉林 + 美景）
- **瞬间定身**（5 个人都定身 + 眼球高速转动）
- **鬼打墙** + **迷路**

### 物理战斗

- 各敏捷得像猴子 → 一蹿就是好几米
- 指挥千头蝙蝠
- 指挥毒虫（蜈蚣 + 蝎子 + 多足爬虫 + 红头蟑螂 + 蚯蚓 + 大蜘蛛）
- 派遣尸鼱
- **捕食孱弱的灵界生物**（**对朵朵特别贪婪**）

### 智慧

- "**果然是有智慧的生物**"
- 会用喷雾剂
- 会讲人类话语："**为什么要对我们赶尽杀绝？人类，你真的以为我们死了么？赫赫，我们只是回归了真神的怀抱**"

### 大黑天魔王召唤（核心伏笔）

> "**计算死者的生辰八字和死期，然后杀十一人，分别取五脏、四肢、阳物以及最后的头颅，精确到时刻，然后融入有邪性的石头中，召唤出一个大黑天出来**"

### 矮人国（神级伏笔）

> "**我要说夜郎国是毁于矮人国之祸，你会不会吃惊？**"

## 关键事件（按章节）

### 第一卷 ch4 — 被陆左抓到

- 陆左按《镇压山峦十二法门》抓矮骡子
- 抓到第一只（这是头人本人）
- 用龙蕨草帽罩住 → 装进袋子

### 第四卷 ch10 — 溶洞迷宫里出现

- 矮骡子出现在矮骡子的溶洞
- 红色眼睛 + 红草帽
- 陆左扑上去 → 撒糯米 → 矮骡子跑了

### 第四卷 ch11 — 指挥毒虫阵

- 10 来个带红帽的小矮个儿跳跃
- 指挥蜈蚣 + 蝎子 + 多足爬虫 + 红头蟑螂 + 蚯蚓 + 大蜘蛛
- 用黑黢黢的虫子袭击
- **刘警官被咬 + 中尸毒**

### 第四卷 ch12 — 贪婪望向朵朵

- 看到朵朵 → **贪婪的目光**
- 紫红色的眼睛死死盯着朵朵
- 喜欢吞噬孱弱的灵界生物
- 朵朵是他们的猎物

### 第四卷 ch13 — 被陆左掐死（复仇）

- 出洞时 5 把枪扫射 → 死绝
- **陆左单独抓住头人**
- "**这把进枪管** → 插进左眼 → 紫红色的玻璃体炸裂"
- 陆左掐住脖子 → 十来秒 → 头人挣扎 → **残存的右眼瞳孔紫红色变淡 + 血丝蔓延**
- **最终头人气绝 → 紫红色眼眸变得黯淡**

### 第四卷 ch16 — 罗福安被鬼上身

- "**为什么要对我们赶尽杀绝？人类，你真的以为我们死了么？赫赫，我们只是回归了真神的怀抱……你手上沾染了头人的鲜血，你身上必受到所有幽冥生物的憎恶，颤抖吧，人类**"
