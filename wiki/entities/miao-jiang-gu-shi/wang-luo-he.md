# 王洛和（Wang Luohe）

> **便宜师叔 / 洛十八徒弟** · 猿尸降 + 食脑猴 + 苍蝇封摄像头 · 第二卷反派 · ch17 已死

## 基本档案

- **出处**：《苗疆蛊事》第二卷
- **身份**：便宜师叔 / 洛十八徒弟 / 降头师
- **化名**：自称"王洛和"（也可能不是真名 → 黑户）
- **年龄**：约 50 岁
- **籍贯**：自称来自东南亚（毛淡棉 = 缅甸孟邦省）
- **真实身份**：滇黔一带或东南亚的降头师（欧阳警官语）
- **外貌**：瘦小 / 皮肤很黑 / 脸型轮廓像东南亚 / 左眼眉上一颗大黑痣 / **人很丑** / 嚼槟榔
- **状态**：**已死**（ch17 死于陆左灵蛊）

## 视觉

- 瘦小的身影
- 穿旧红色羽绒服（雨林里穿）+ 衣袖和兜旁边有泥土
- 皮肤很黑 + 脸型轮廓像东南亚
- 年纪约 50 岁
- **左眼眉毛上面一颗大大的黑痣**
- **人很丑** → 陆左："皱纹密布，歪嘴斜眼，丑的让人厌恶，想吐"
- 冷笑 / 嘴一动一动 / 在嚼槟榔
- 眼神尖利如破碎的玻璃渣子

## 能力（深度版）

### 猿尸降（核心）

- **山魈（Mandrillus sphinx）**的尸体炼化
- 涂抹人体 → 化身山魈
- **力大无匹 + 一跃几丈**
- 古时邪恶巫师 / 宗教人士 → 炼制**护坛武士**
- **副作用**：每月月光如水 + 圆月当空 → 三万七千穴窍奇痒 + 毛发长出 + 皮肤鲜血淋漓 → 痛苦不堪 → 吸食鸦片解痛 → 长此以往精神异常 → **寿命不过 10 年**

### 食脑猴（塔特原狐猴）

- 师叔的护法
- 体型小猫那么大
- 脸颊、胸脯和四肢内侧深橙色 / 背部红褐色 / 黑色尾巴有白尖
- **学名塔特原狐猴（食脑猴）**
- **沟通冥界 + 吞噬灵体**
- 普通猴子是杂食 → 它喜欢**食腐尸脑**
- **朵朵的危险**（如果被抓）

### 苍蝇封摄像头

- 老油条降头术的标志
- 让苍蝇糊住摄像头 → 掩护小偷入室

### 癫蛊

- 中蛊后半日发作 → 人心昏 + 头眩 + 笑骂无常
- 饮酒时毒发 → 人痒难耐 + 忿怒凶狠 + 俨如癫子
- 普通治法：**嚼用槟榔**
- **陆左金蚕蛊自动解毒**（百毒莫进）

### 虫瘿（僵尸虫）

- 微小的生物、病菌 → 肉眼所不能见 → 又名僵尸虫、傀儡虫
- 来自南美洲原始丛林中的蜜蜂
- 蜜蜂生前被虫瘿感染 → 死后尸体仍被生物电控制 → 乱飞 + 攻击生物
- 炼制者用音频震荡指挥尸体
- **不传染**
- 跟湘西赶尸相似但不同

### 罂粟 + 砒霜

- 快速致死药引
- 配合虫瘿 → 服过之人必死无疑

### 血手掌印

- 早期南疆部族山寨时期的挑战标志
- 在对方村口 / 井边 / 屋旁印血淋淋手印
- 以作警示 → 双方斗蛊
- 跟西方绅士决斗扔白手套一个原理

## 关键事件（按章节）

### ch7-8 — 朵朵被窃 + 电话讨债

### ch16 — 小美之死（师叔的复仇）

- 王洛和再次现身

- 陆左**下灵蛊**："发作吧，全身溃烂、身首分离、千虫噬心吧！"

### ch17 — 王洛和死于灵蛊

- **死在附近开发园区一家旅馆的日租房**
- 全身溃烂 + 高度腐化 + 皮与肉分离
- 血淋淋的肉身爬满白色蛆虫
- 头在床上 + 肠子拉了 **6 米**
- 房间像屠宰场 + 熏臭得跟粪坑一样
- 萧克明侦察结果
