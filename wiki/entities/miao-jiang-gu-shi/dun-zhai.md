# 敦寨 (Dūn Zhài)

> **苗疆古寨** · 外婆龙老兰的居住地 · 陆左人生的根

## 基本档案

- **出处**：《苗疆蛊事》第一卷
- **位置**：湘西苗疆，西南少数民族地区
- **类型**：**生苗寨**（未汉化，与世隔绝）
- **住户**：苗人，保留原始宗教
- **特征**：穷山恶水刁民
- **距陆左家镇子**：约 1-2 小时车程

## 关键地标（深度版）

### 寨子中央

- **巨型老槐树**（寨子中央）
- **鼓楼**
- **晒谷场**
- **堂庙道场**（外婆的祭祀场所）→ 陆左拜祖地点

### 外婆老宅

- **老宅**（外婆的住所，已归小舅名下）
- **堂屋**（陆左家）
- **卧室**（外婆卧床处）→ 外婆临终下蛊 + 死亡
- **神龛**（十来个牌位）→ 历代祖师
- **屋后空地** → 埋金蚕蛊泥坛子处
- **堂庙道场后井水** → 神圣水源 → 功德汤冰镇

## 文化特征（深度版）

### 苗寨分类

- **生苗**：与世隔绝的苗人
- **熟苗**：被汉化的苗人，混居，不住寨子，不祭祀，不过苗节，甚至不会说苗话

### 苗人善养蛊

- 大山没有开发 → 人迹罕至
- 毒蛇、蜈蚣、蜥蜴、蚯蚓、蛤蟆等毒物漫山遍野
- 见多了就慢慢了解毒性

### 苗寨权威结构

- **族长权威比天大**
- **外婆是族长唯一怕的** → 龙老兰地位

### 信仰

- **生苗与世隔绝**
- **不信汉族政府**
- **拜神 / 祭祀 / 驱鬼**
- **信仰萨满 / 原始宗教**

## 现实对照（深度版）

- **湘西地区真实存在的苗寨**
- **2004 年通公路**前为烂泥路
- **包车 / 中巴**可达
- **距陆左家镇子约 1-2 小时车程**

## 关键事件（按章节）

### ch1 — 陆左探病 + 外婆下蛊

- 2007-08-末：陆左接外婆重病消息
- 母亲告知外婆回敦寨去了（"死也要死在敦寨"）
- **敦寨苗寨生活了 86 年**：井水甜、稻谷香、风里有油菜花香
- 第二天去敦寨
- 包面包车 → 大半多小时到
- **陆左见到**：巨型老槐树 + 鼓楼 + 晒谷场 + 堂庙道场
- 聚在老宅里的人：小姨远在新疆，其他亲戚都回来
- 外婆浑浑噩噩两天
- **清醒瞬间 → 下金蚕蛊**（外婆卧室）
- 次日外婆死亡

### ch11 — 外婆托梦 + 陆左拜祖

- **外婆托梦三件事**：
  - 回敦寨老屋磕头拜祖
  - 老屋里所有东西避秽不取
  - 《镇压山峦十二法门》书烧掉
- **陆左拜祖**：
  - 一早买香烛纸钱
  - 三轮车去敦寨
  - **外婆家阴气浓重**
  - 院子里土地下似乎埋着无数的虫尸长蛇
  - **仪式**：
    - 点燃香烛
    - 对神龛上十来个牌位三叩九拜
    - 高呼："历代祖师爷在上，小子陆左在下，蒙外婆龙老兰庇佑，收入门中，望众祖师爷垂怜，不弃我资质浅薄，佑我一世平安，无灾无难。"
  - **感应**：神龛牌位气旋升起 → 浑身暖洋洋 → 通体舒透
  - **收尾**：
    - 烧纸 + 收拾干净
    - 片纸不拿
    - 鞋底泥刮蹭在门坎散落堂屋
- **永别**：
  - 老宅已经归小舅名下
  - 陆左走时深深看一眼 → **这辈子都没有再来过**

### 神秘的院子

- 外婆托梦后 → 陆左发现院子里土地下似乎埋着无数的虫尸长蛇
- 这是养蛊人 / 神婆的典型做法
- **圆桌化推断**：地下埋着几十年的蛊毒生态
