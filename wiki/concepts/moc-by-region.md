# MOC · 按地域

> 本 MOC 把妖怪按**地理/空间**分组,反映中国古代的山海崇拜与异域想象。

## 四大地域维度

### 1. 山系妖怪 (出现 3110 次「山」)

- 山神([[type-mountain-demon|类型-山妖]]) / 山精 / 山魈
- [[ancient-text-shanhaijing|古籍-山海经]] 的山经主体是山系妖怪
- 代表: 章莪之山、招摇之山、青丘之山

### 2. 海系妖怪 (出现 1165 次「海」)

- 海神([[type-sea-demon|类型-海妖]]) / 蛟 / 鲛人
- [[ancient-text-shanhaijing|古籍-山海经]] 的海经主体是海系妖怪
- 代表: 鲛人、蛟、海神

### 3. 水系妖怪 (出现 1168 次「水」)

- 水鬼 / 蛟龙 / 河神
- [[ancient-text-soushenji|古籍-搜神记]] 大量记载
- 代表: 长江水神、黄河水神

### 4. 海外 + 异域妖怪

- 海外贡兽 / 异域奇物
- [[ancient-text-youyang-zazu|古籍-酉阳杂俎]] / [[ancient-text-taipingguangji|古籍-太平广记]] 记载
- 代表: 嗽金鸟(海外贡鸟)、望加锡海马(海外贡兽)

## 跨地域主题

- **山海崇拜**: 山经([[ancient-text-shanhaijing|古籍-山海经]] 5 篇) + 海经(8 篇) + 大荒经(4 篇) + 海内经(1 篇)
- **异域想象**: 海外 + 异域 + 贡兽
- **地理想象**: 中土 + 四海 + 六合之外

## 阅读路径

**想了解中国古代的山海世界观** → 从 [[ancient-text-shanhaijing|古籍-山海经]] 的山经、海经开始
**想了解海外贡兽** → 进 [[ancient-text-youyang-zazu|古籍-酉阳杂俎]] 或 [[ancient-text-taipingguangji|古籍-太平广记]]
**想了解本土妖怪的地域分布** → 按朝代读
