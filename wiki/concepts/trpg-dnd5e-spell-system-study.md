## 1. 跑团是什么(世界观定位)

跑团 = **桌面角色扮演游戏**(Tabletop Role-Playing Game, TRPG)= 以 **D&D(龙与地下城)5E / 5R** 为代表的奇幻协作即兴戏剧。

> 新手指南:「D&D 的核心是『**通过对话完成的集体即兴小说创作**』,融合了协作叙事、战术博弈与即兴表演的特质。」

**3 大特征**:
1. **社交属性强**(不是战斗游戏)
2. **协作叙事**(DM + 玩家共同写故事)
3. **d20 核心机制**(简洁概率系统,每次判定 = d20 + 修正值 ≥ DC)

**与 RPG 网游的区别**:
- 无需屏幕,纸笔 + 骰子 + 想象力
- 无固定剧本,DM 即时响应玩家选择
- 数值有限(不膨胀),1 点属性 = 5% 成功率

**重要警示**(新手常见误判):
- ❌「D&D 是杀怪游戏」= 大错特错
- ❌「需要熟记数百页规则」= 大错特错
- ✅「通过对话完成的集体即兴小说」= 正确

## 2. 施法系统的双重逻辑(准备 vs 已知)

D&D 5E 法术系统最大特点 = **不同职业施法逻辑不同**,分两大类:

### 2.1 准备施法者(每日长休后准备)

| 职业 | 法术来源 | 数量 |
|:--|:--|:--|
| 法师(Wizard) | 自己的法术书 | 全部法术书中的任意 |
| 牧师(Cleric) | 神祇赐予 | 全职业法术库 + 领域赠予的已知法术 |
| 德鲁伊(Druid) | 自然世界共鸣 | 全职业法术库 |
| 圣武士(Paladin) | 誓言赠予 | 全职业法术库 + 誓言赠予的已知法术 |
| 奇械师(Artificer) | 魔法注入科技 | 全职业法术库 |

**关键限制**:每天只能施放**今天准备好的**法术,长休后必须重新选择。

### 2.2 已知施法者(升级时学习,不可更换)

| 职业 | 法术数量 | 特色 |
|:--|:--|:--|
| 术士(Sorcerer) | 极少(偏科) | 术法点改规则(成双 / 瞬发) |
| 吟游诗人(Bard) | 中等 | 万金油 + 高环偷学其他职业法术 |
| 邪术师(Warlock) | 极少 | 法术位永远是最高环级 + 短休回满 |
| 游侠(Ranger) | 中等 | 弓箭 + 自然魔法 |

**关键限制**:升级时学会的固定法术,平时不可更换。

### 2.3 叙事视角(世界观解释)

| 类型 | 法力来源 | 叙事比喻 |
|:--|:--|:--|
| 准备施法 | 神祇 / 自然 / 奥秘知识 | 「把已经存在的法术下载到记忆」 |
| 已知施法 | 血脉 / 契约 / 韵律 | 「逐步激发体内潜能」 |
| 法师(混合) | 自我研习 | 「学得太多导致很像准备施法者的已知施法者」 |

## 3. 法术位(Spell Slot)= 一次性电池

**定义**:施放 1 环及以上法术必须消耗的资源。

**与「蓝条」的区别**:
- ❌ 不是持续消耗的蓝条
- ✅ 是**一次性电池** = 不同容量(1-9 环),用完即弃

**戏法(Cantrip)**:0 环法术,不需要法术位,**等于法系职业的平 A**。威力随等级提升(5/11/17 级自动升级)。

**资源管理铁律**:
- 长休(Long Rest,8 小时睡)→ **回满法术位**(大部分职业)
- 短休(Short Rest,1 小时休息)→ 部分职业(邪术师)回满
- **核心教训**:不要把高级法术位当平 A 用,留到 Boss 战

## 4. 施法三大检定

| 检定类型 | 适用法术 | 公式 | 谁掷 |
|:--|:--|:--|:--|
| **命中检定** | 攻击型法术(如火焰箭) | `d20 + 法术攻击加值 ≥ 敌人 AC` | 玩家 |
| **豁免检定** | 控制型法术(如火球术) | `DC = 8 + 施法属性调整值 + 熟练加值`,敌人掷 d20 | DM 帮敌人掷 |
| **自动成功** | 治疗 / 增益型(如治愈真言) | 不需检定 | — |

**关键属性 vs 施法职业**:

| 关键属性 | 职业 | 原因 |
|:--|:--|:--|
| 智力 | 法师、奇械师 | 奥秘知识需要逻辑分析 |
| 感知 | 牧师、德鲁伊、游侠 | 神祇 / 自然共鸣需要直觉 |
| 魅力 | 术士、吟游诗人、圣武士、邪术师 | 法力来自血脉 / 韵律 / 信念 |

**熟练加值表**(影响所有检定):

| 玩家等级 | 熟练加值 |
|:--|:--|
| 1-4 | +2 |
| 5-8 | +3 |
| 9-12 | +4 |
| 13-16 | +5 |
| 17-20 | +6 |

## 5. 升环施法(Upcasting)

**定义**:用高环法术位施展低环法术(如 3 环位放 1 环火球)。

**效果**:大部分法术升环后会产生额外效果(伤害骰 +1d / 目标数量 +X)。

**注意事项**:
- 1 环法术用 3 环位放 = 在那一刻它就是 3 环法术
- 可用升环 = 高环法术位有剩余 + 低环法术升环有收益

**典型场景**:3 环位时 1 环魔法飞弹可以多打一颗(基础 3 颗 + 1 颗 = 4 颗)。

## 6. 专注(Concentration)

**定义**:维持持续性法术(如加速术、隐形术、变形术)的核心机制。

**规则**:
- 同一时间**只能专注一个法术**
- 受伤需通过**体质豁免**(DC 10 或伤害一半,取高)
- 施放另一个需专注的法术 = 自动中断前一个

**5E 引入专注的目的**:防止旧版「法师套 10 层 Buff 变高达」的数值堆叠。

**最高优先级**:**高级施法者的第一要务是保命与保专注**。

## 7. 仪式施法(Ritual)

**定义**:多花 10 分钟施法,从而免于消耗任何法术位的特殊施法方式。

**白嫖场景**:无限次地用仪式召唤魔宠、鉴定装备、解决非战斗谜题。

**谁可以仪式施法**:

| 职业 | 仪式施法 | 获取方式 |
|:--|:--|:--|
| 法师 | ✅ 天生 | 职业特性 |
| 牧师 | ✅ 天生 | 职业特性 |
| 德鲁伊 | ✅ 天生 | 职业特性 |
| 吟游诗人 | ✅ 天生 | 职业特性 |
| 奇械师 | ✅ 天生 | 职业特性 |
| 邪术师 | ❌ 需要专长或魔契 | 仪式施法者专长 / 远古奥秘之书 |
| 术士 | ❌ 需要专长 | 仪式施法者专长 |
| 圣武士 | ❌ 需要专长 | 仪式施法者专长 |
| 游侠 | ❌ 需要专长 | 仪式施法者专长 |

## 8. 八大魔法学派(Schools of Magic)

所有法术被归类在 8 个学派中:

| 学派 | 本质 | 标志性法术 | 偏好职业 |
|:--|:--|:--|:--|
| **防护**(Abjuration) | 创造屏障,抵抗变化 | 护盾术、解除魔法 | 法师、圣武士 |
| **咒法**(Conjuration) | 位移与召唤 | 迷踪步、召唤次级恶魔 | 法师、德鲁伊 |
| **预言**(Divination) | 洞悉未来,探测未知 | 鉴定术、秘法眼 | 法师、牧师 |
| **惑控**(Enchantment) | 操纵与改写心智 | 魅惑人类、暗示术 | 吟游诗人、邪术师 |
| **塑能**(Evocation) | 压缩与驱使能量 | 火球术、魔法飞弹 | 法师、术士 |
| **幻术**(Illusion) | 欺骗感官 | 无声幻影、高等隐形术 | 法师、术士 |
| **死灵**(Necromancy) | 对生命力进行操控 | 操纵死尸、致盲/耳聋术 | 邪术师、牧师 |
| **变化**(Transmutation) | 对物体形态进行变幻 | 变形术、飞行术 | 法师、德鲁伊 |

**实战应用**:
- 法师**学派专精**(School Specialization)= 同学派抄卷轴时间和费用减半
- 不同学派有不同施法增益(如塑能学派 +1 伤害骰)

## 9. 新手 12 大误区(避坑清单)

| # | 误区 | 正确做法 |
|:--|:--|:--|
| 1 | 望文生义(以为【颤栗之触】是近战) | 仔细读法术描述,看距离 / 伤害类型 / 形状 |
| 2 | 打断自己的专注(套 Buff 后扔攻击法术) | 检查「需要专注」标记,同时间只专注一个 |
| 3 | 无视掩护规则(敌人躲在掩体后) | 用范围伤害(火球)或跑到侧翼 |
| 4 | 贴脸射击(被近战还打远程) | 远程攻击 5 尺内有敌人 = 劣势,应后退或闪现 |
| 5 | 乱用高环控制对付强项豁免 | 看怪物属性弱点:法师怪怕体质,肉盾怪怕智力 |
| 6 | 忘了附赠施法规则 | 用附赠施法 = 动作只能放戏法 |
| 7 | 不知道自己法术要什么材料 | DM 问「你有 50 gp 的钻石吗」前自己先查 |
| 8 | 治疗强迫症(顶着伤害奶人) | 战斗中奶人通常亏,优先杀怪 |
| 9 | 把法术位当平 A 用 | 打小怪用戏法,Boss 战才用法术位 |
| 10 | 轮到自己才开始翻书 | 在别人回合就想好对策 |
| 11 | 不抄卷轴(直接当消耗品) | 法师把卷轴抄进法术书长期使用 |
| 12 | 只学伤害法术 | 必备羽落术 / 魔法飞弹 / 治愈真言 / 护盾术 |

## 10. 跑团法术书工具(5E/5R 双版本)

**核心功能**:
- 法术库浏览 + 多维筛选(职业 / 环阶 / 学派 / 来源)
- 已选法术管理(队伍 = 准备 / 已知法术清单)
- 法术位追踪(可视化 ① 1/4 格式)
- 多法术表管理(DM 同时管理多个角色 / 怪物)
- 备份恢复(本地化存档码,跨设备导入)

**5E vs 5R 区别**:

| 维度 | 5E(经典五版 2014) | 5R(全新五版 2024) |
|:--|:--|:--|
| 规则基础 | 2014 玩家手册等核心 | 2024 最新修订版 |
| 界面色调 | 深红色 | 深金色 |
| 法术内容 | 基础 + 全部扩展 | 调整 + 新增 + 完整扩展 |
| 跨版本兼容 | 5R 导入 5E 可能丢失 | 5E 导入 5R 完整保留 |

**关键洞察**:
- 5E 升级 5R 时法术只增不减 = 5E → 5R 安全
- 5R 降级 5E 时可能丢法术 = 5R → 5E 有风险

**打印功能**(PC 端 Chrome/Edge 推荐):
- 扑克牌(A4 3×3 排版)→ 纵向打印
- 塔罗牌(A4 2×4 排版)→ 横向打印
- 明信片(A4 2×2 排版)→ 纵向打印

**数据存储**:纯本地 LocalStorage,卸载浏览器会丢数据,建议定期导出存档码。
